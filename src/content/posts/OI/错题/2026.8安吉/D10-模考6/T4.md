> [!NOTE]- 原题呈现
> # 题目描述
>
> 输入一个长度为 $n$ 的数列 $a_1, a_2, \cdots, a_n$，问有多少个长度大于等于 $2$ 的不上升的子序列满足：
>
> $$
> \prod_{i=2}^{k} \binom{a_{b_{i-1}}}{a_{b_i}} \bmod 2 > 0
> $$
>
> 输出这个个数对 $1000000007$ 取模的结果．
>
> ## 输入格式
>
> 第一行一个整数 $n$．
>
> 接下来 $n$ 行，每行一个整数，第 $i$ 行表示 $a_i$．
>
> ## 输出格式
>
> 一行一个整数表示答案．
>
> ## 样例
>
> ### 样例输入
>
> ```
> 4
> 15
> 7
> 3
> 1
> ```
>
> ### 样例输出
>
> ```
> 11
> ```
>
> ## 数据范围
>
> - 前 $10\%$ 的测试点：$n \le 9$，$1 \le a_i \le 13$．
> - 前 $20\%$ 的测试点：$n \le 17$，$1 \le a_i \le 20$．
> - 前 $40\%$ 的测试点：$n \le 1911$，$1 \le a_i \le 4000$．
> - 前 $70\%$ 的测试点：$n \le 2017$．
> - 前 $85\%$ 的测试点：$n \le 100084$．
> - $100\%$ 的测试点：$1 \le n \le 211985$，$1 \le a_i \le 233333$．
> 
> 所有的 $a_i$ **互不相同**，即不存在 $i \neq j$ 满足 $a_i = a_j$．

我们可以尝试使用 dp 来解决子序列问题．

定义 `dp[i]` 表示以第 $i$ 个数结尾能够有多少满足要求的子序列．由于题意要求所有组合数的乘积模 2 大于 0，那就是要求所有组合数都是奇数．

转移方程为：

$$
dp[i]=1+\sum_{j}^{j <i}dp[j],\binom{j}{i}\bmod 2=1
$$

可以使用递推公式快速算出组合数．

这样能够拿到 40 pts．当 $a_i$ 到二十万的数据规模就无法处理了，那该怎么办呢？

**Lucas 定理**：

$$
\binom{x}{y}\bmod p=\binom{\lfloor x/p\rfloor}{\lfloor y/p\rfloor}\binom{x\bmod p}{y\bmod p}\bmod p
$$

当 $p=2$ 时，

$$
\binom{x}{y}\bmod 2=\binom{\lfloor x/2\rfloor}{\lfloor y/2\rfloor}\binom{x\bmod 2}{y\bmod 2}\bmod p
$$

将 $\binom{\lfloor x/2\rfloor}{\lfloor y/2\rfloor}$ 拆解，可得：

$$
\binom{x}{y}\bmod 2=\binom{\lfloor x/4\rfloor}{\lfloor y/4\rfloor}\binom{\lfloor x/2\rfloor\bmod 2}{\lfloor y/2\rfloor\bmod 2}\binom{x\bmod 2}{y\bmod 2}\bmod p
$$

像这样拆解，最终可得：

$$
\binom{x}{y}\bmod 2=\prod\binom{x_i}{y_i}
$$

其中，$x_i,y_1$ 分别表示 $x,y$ 中二进制表示的第 $i$ 位．

当且仅当 $x_i=0,y_i=1$ 时，$\binom{x_i}{y_i}=0$，故 $\binom{x}{y}\bmod 2=1$ 等价于 $\forall i,x_i=0\Rightarrow y_i=0$，即位运算中 $x\wedge y=y$． 其实就是 $x$ 是 $y$ 二进制中的子集．

因此，在 dp 时，尝试子集枚举．具体来说，遍历到 $a[i]$ 时，先将 $f[i]$ 增加 1，表示 $a[i]$ 单独成一组．再枚举 $a[i]$ 的所有子集 $k$，若 $k$ 在后面出现过（设其处于 $a[j]$），则说明 $f[i]$ 可以转移到 $f[j]$，将 $f[i]$ 贡献给 $f[j]$．

子集枚举可以使用下面的代码：

```cpp
for (int j = (a[i] - 1) & a[i]; j > 0; j = (j - 1) & a[i])
```

请注意：由于题目中所要求的序列长度大于等于 2，因此最终答案需要减去 $n$ 个长度为 1 的序列．

**标程**

```cpp
#include <bits/stdc++.h>
using namespace std;
#define int long long
const int N = 240000;
const int MOD = 1e9 + 7;

int n, a[N], id[N], f[N], ans;

signed main() {
    cin >> n;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        id[a[i]] = i;
    }
    for (int i = 1; i <= n; i++) {
        (f[i] += 1) %= MOD;
        (ans += f[i]) %= MOD;
        for (int j = (a[i] - 1) & a[i]; j > 0; j = (j - 1) & a[i]) {
            if (id[j] > i)
                (f[id[j]] += f[i]) %= MOD;
        }
    }
    cout << ans - n;
    return 0;
}
```
