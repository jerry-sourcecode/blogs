> [!NOTE]- 原题呈现
> ## 题目描述
>
> 你需要维护一个序列，初始长度为 $n$．序列中的每个元素带有两个标记：权值 $a_i$ 和颜色 $c_i$．
>
> 本题要求**强制在线**．
>
> 接下来有 $m$ 次操作：
>
> - `1 l r x`：仅关注下标在 $[l, r]$ 内的元素．把其中权值**不大于** $x$ 的元素按原下标递增顺序取出来，形成一个子序列．对于这个子序列，若相邻两个元素颜色相同，则认为它们属于同一段．求这个子序列共有多少段．
> - `2 x y`：在序列尾部插入一个新的元素，其权值为 $x$，颜色为 $y$．
> 
> 例如：某次查询得到的颜色序列为
>
> $$
> [1,4,4,6,6,6,2,5,5]
> $$
>
> 那么会被分成
>
> $$
> [1], [4,4], [6,6,6], [2], [5,5]
> $$
>
> 共 $5$ 段．
>
> ## 输入格式
>
> 从文件 `subsequence.in` 中读入数据．
>
> 第一行三个整数 $n, m, k$，分别表示序列的初始长度、操作次数和是否强制在线．
>
> 接下来两行，第一行 $n$ 个整数，表示 $a_i$；第二行 $n$ 个整数，表示 $b_i$（即颜色 $c_i$）．
>
> 接下来 $m$ 行，每行首先一个整数 $t$，表示本次操作的种类．
>
> - 若 $t=1$，接下来三个整数 $l, r, x$，描述一次查询．
> - 若 $t=2$，接下来两个整数 $x, y$，描述一次插入．
> 
> 对于 $k=0$，不要求强制在线．
> 对于 $k=1$，要求输入的 $l, r, x, y$ 均对上一次查询的结果按位异或，即 $l' = l \oplus ans$，若上一次查询不存在，则 `ans = 0`．
>
> 解码方式示例：
>
> ```cpp
> int n, m, k;
> cin >> n >> m >> k;
> for (int i = 1 ; i <= m ; i++) {
>     cin >> t;
>     if (t == 1) {
>         int l, r, x;
>         cin >> l >> r >> x;
>         l ^= ans * k;
>         r ^= ans * k;
>         x ^= ans * k;
>     } else {
>         int x, y;
>         cin >> x >> y;
>         x ^= ans * k;
>         y ^= ans * k;
>     }
> }
> ```
>
> ## 输出格式
>
> 输出到文件 `subsequence.out` 中．
>
> 对于每个操作 $1$，每行输出一个整数表示查询的结果．
>

> ## 数据范围
>
> 对于 $100\%$ 的数据，保证：
>
> - $1 \le n, m \le 3 \times 10^5$；
> - $0 \le k \le 1$；
> - $1 \le op \le 2$；
> - $1 \le l, r \le n$（解码后）；
> - $1 \le a_i, c_i, x, y \le 10^9$．
> 
> ### 子任务
>
> 本题采用捆绑测试，你必须通过子任务内所有测试点才能获得该子任务分数．
>
> | 测试点编号 | $n, m \le$ | 特殊性质 |
> | :---: | :---: | :--- |
> | $1 \sim 10$ | $10^3$ | 无 |
> | $11 \sim 20$ | $10^5$ | 无 |
> | $21 \sim 30$ | $3\times10^5$ | $k=0$ |
> | $31 \sim 40$ | $3\times10^5$ | 操作 $1$ 的 $l=1$ |
> | $41 \sim 50$ | $3\times10^5$ | 无 |

涉及到区间查询，单点修改，考虑使用树状数组或是线段树，但这道题并非简单的求区间和，于是选择使用线段树．

对于线段树的每一个节点，我们记录一个 `vector`，`vector` 中的每一个元素是一个四元组 `[x, lcol, rcol, cnt]`，

- `x` 为选择的权值．
- `lcol` 是选择权值为 `x` 时，该区间最左端有效元素的颜色．
- `rcol` 是选择权值为 `x` 时，该区间最右端有效元素的颜色．
- `cnt` 是选择权值为 `x` 时，该区间所有有效元素一共能组成多少段．

将这个四元组类型定义为结构体 `Node`．将包含 `Node` 的 `vector` 定义为类 `Nodes`．`Nodes` 即为线段树中每一个端点的数据类型．

对于该区间内每一个可能的 `x`，都建一个 `Node`，保存在该区间节点的 `Nodes` 中．

对于两个 `Node` $a,b$ 之间的合并，可以表示为：

- 对于 `x`，取 $\max\{a.x,b.x\}$．
- 对于 `lcol`，取 $a.lcol$．
- 对于 `rcol`，取 $b.rcol$．
- 对于 `cnt`，
	- 若 $a.rcol = b.lcol$，即两个节点中间部分的颜色可以合并成一大段，答案取 $a.cnt + b.cnt-1$．
	- 否则，取 $a.cnt + b.cnt$．

```cpp
friend Node operator+(const Node a, const Node b) {
	// 对于所有权值为 0 的点，我们定义它为空 (null)，一个 Node 加上空还是该 Node
	if (a.x == 0)
		return b;
	if (b.x == 0)
		return a;
	Node ans;
	ans.x = max(a.x, b.x);
	ans.lcol = a.lcol;
	ans.rcol = b.rcol;
	ans.cnt = a.cnt + b.cnt - (a.rcol == b.lcol);
	return ans;
}
```

对于两个 `Nodes` $m,n$（显然，$m,n$ 中的元素按照 $.x$ 升序排列）需要合并到 $k$，可以采用类似归并排序的方法．其宗旨为：

> 对于每一个存在于 $m$ 中的四元组 $i$，查找 $n$ 中最后一个四元组 $j$ 满足 $i.x \geq j.x$．此时 $j$ 中统辖的所有元素权值是节点 $n$ 所代表区间中所有小于等于 $i.x$ 的元素．将这两个四元组合并，加入到 $k$ 中，对于每一个存在于 $n$ 中的四元组也是如此．

在程序中，我们使用双指针，指针 $i$ 指向 $m$，指针 $j$ 指向 $n$．初始时，$i,j$ 都指向 $m,n$ 第一个元素的前一个位置．在每一次循环时，我们需要决定主场节点：

- 检查两个指针是否指向了两个 `vector` 的最后一个元素．
	- 若都指向，结束循环．
	- 若指针 $i$ 指向了 $m$ 的最后一个元素，则主场节点为 $n$．
	- 若指针 $j$ 指向了 $n$ 的最后一个元素，则主场节点为 $m$．
	- 若以上情况都不满足，则比较指针 $i$ 指向的下一个元素 $p$ 和指针 $j$ 指向的下一个元素 $q$ 的大小
		- 若 $p<q$ 则主场节点为 $n$．
		- 若 $p>q$ 则主场节点为 $m$．
		- 否则，主场节点同时为 $m,n$．
- 在决定主场节点之后，将主场节点对应的指针向后移动一次．
- 最后，将 $i$ 指向的元素和 $j$ 指向的元素合并，加入节点 $k$．

```cpp
friend Nodes operator+(const Nodes a, const Nodes b) {
	Nodes ans;
	ans.l = a.l;
	ans.r = b.r;
	int i = -1, j = -1;
	while (true) {
		Node tmp;
		bool isInEndA = i + 1 >= a.size();
		bool isInEndB = j + 1 >= b.size();
		if (isInEndA && isInEndB)
			break;
		if (isInEndB || (!isInEndA && a[i + 1].x < b[j + 1].x)) {
			i++;
			tmp = a[i];
			if (j != -1) {
				tmp = tmp + b[j];
			}
		} else if (isInEndA || a[i + 1].x > b[j + 1].x) {
			j++;
			tmp = b[j];
			if (i != -1) {
				tmp = a[i] + tmp;
			}
		} else {
			i++;
			j++;
			tmp = a[i] + b[j];
		}
		ans.push_back(tmp);
	}
	return ans;
}
```

建树和修改的代码和普通线段树大差不差，因为没有区间修改，所以都不需要 `pushup`．

由于最多会有 $m$ 次插入操作，所以要预留出这些空间．线段树的大小要开 $m+n$．

```cpp
void build(int t, int l, int r) {
	f[t].l = l, f[t].r = r;
	if (l == r) {
		if (l > n) { // 大于 n 的点当前还是空的
			return;
		}
		Node nd;
		nd.x = a[l];
		nd.lcol = b[l];
		nd.rcol = b[l];
		nd.cnt = 1;
		f[t].push_back(nd);
		return;
	}
	int mid = (l + r) / 2;
	build(t * 2, l, mid);
	build(t * 2 + 1, mid + 1, r);
	pushup(t);
}
void pushup(int t) { f[t] = f[t * 2] + f[t * 2 + 1]; }
void Modify(int t, int pos, int a, int b) {
	if (f[t].l == pos && f[t].r == pos) {
		f[t].push_back({a, b, b, 1});
		return;
	}
	if (f[t].l > pos || f[t].r < pos) {
		return;
	}
	Modify(t * 2, pos, a, b);
	Modify(t * 2 + 1, pos, a, b);

	pushup(t);
}
```

至于查询操作，需要注意：

- 若当前区间被查询区间完全覆盖，则需要使用 `upper_bound` 找到当前 `Nodes` 中所有的 `Node`，满足权值 $x$ 小于等于查询权值 $qx$，其中权值最大的一个．将这个节点返回．
- 若当前区间和查询区间完全没有交集，则返回一个空的 `Node`（在本程序中，权值为 0 的 `Node` 为空的 `Node`，权值默认为 0），表示什么都没有．

```cpp
Node Query(int t, int x, int y, int tgt) {
	if (f[t].l >= x && f[t].r <= y) {
		auto it = upper_bound(f[t].begin(), f[t].end(), tgt);
		if (it == f[t].begin())
			return Node();
		return *(it - 1);
	}
	if (f[t].l > y || f[t].r < x) {
		return Node();
	}
	return Query(t * 2, x, y, tgt) + Query(t * 2 + 1, x, y, tgt);
}
```

这样线段树就建完了．

在处理查询时，调用线段树的 `Query` 方法，收到节点中的 `cnt` 即为答案．

在处理插入时，直接调用线段树的 `Modify` 方法即可．

但是这样每次插入一个节点，每一层都会调用一次 `pushup`，`pushup` 复杂度最高 $O(n)$，每一次查询的复杂度为 $O(n\log n)$．$q$ 次查询的复杂度为 $O(nq\log n)$，不如暴力．

仔细想想，对于一个区间，只有其中的全部元素都被插入之后，这个区间才会被访问到．因此，只需要在 $pos=r$ 的时候执行一次 `pushup` 即可．

```cpp
void Modify(int t, int pos, int a, int b) {
	if (f[t].l == pos && f[t].r == pos) {
		f[t].push_back({a, b, b, 1});
		return;
	}
	if (f[t].l > pos || f[t].r < pos) {
		return;
	}
	Modify(t * 2, pos, a, b);
	Modify(t * 2 + 1, pos, a, b);

	if (f[t].r == pos) {
		pushup(t);
	}
}
```

**标程**

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 3e5 + 100;
const int INF = 0x3f3f3f3f;
int n, m, k, a[2 * N], b[2 * N];
int l, r, x, y, ans;

struct SegmentTree {
    struct Node {
        int x = 0, lcol = 0, rcol = 0, cnt = 0;
        friend Node operator+(const Node a, const Node b) {
            if (a.x == 0)
                return b;
            if (b.x == 0)
                return a;
            Node ans;
            ans.x = max(a.x, b.x);
            ans.lcol = a.lcol;
            ans.rcol = b.rcol;
            ans.cnt = a.cnt + b.cnt - (a.rcol == b.lcol);
            return ans;
        }
        friend bool operator<(const int a, const Node b) { return a < b.x; }
    };
    class Nodes : public vector<Node> {
      public:
        int l, r;
        friend Nodes operator+(const Nodes a, const Nodes b) {
            Nodes ans;
            ans.l = a.l;
            ans.r = b.r;
            int i = -1, j = -1;
            while (true) {
                Node tmp;
                bool isInEndA = i + 1 >= a.size();
                bool isInEndB = j + 1 >= b.size();
                if (isInEndA && isInEndB)
                    break;
                if (isInEndB || (!isInEndA && a[i + 1].x < b[j + 1].x)) {
                    i++;
                    tmp = a[i];
                    if (j != -1) {
                        tmp = tmp + b[j];
                    }
                } else if (isInEndA || a[i + 1].x > b[j + 1].x) {
                    j++;
                    tmp = b[j];
                    if (i != -1) {
                        tmp = a[i] + tmp;
                    }
                } else {
                    i++;
                    j++;
                    tmp = a[i] + b[j];
                }
                ans.push_back(tmp);
            }
            return ans;
        }
    } f[N * 8];
    void build(int t, int l, int r) {
        f[t].l = l, f[t].r = r;
        if (l == r) {
            if (l > n) {
                return;
            }
            Node nd;
            nd.x = a[l];
            nd.lcol = b[l];
            nd.rcol = b[l];
            nd.cnt = 1;
            f[t].push_back(nd);
            return;
        }
        int mid = (l + r) / 2;
        build(t * 2, l, mid);
        build(t * 2 + 1, mid + 1, r);
        pushup(t);
    }
    void pushup(int t) { f[t] = f[t * 2] + f[t * 2 + 1]; }
    void Modify(int t, int pos, int a, int b) {
        if (f[t].l == pos && f[t].r == pos) {
            f[t].push_back({a, b, b, 1});
            return;
        }
        if (f[t].l > pos || f[t].r < pos) {
            return;
        }
        Modify(t * 2, pos, a, b);
        Modify(t * 2 + 1, pos, a, b);

        if (f[t].r == pos) {
            pushup(t);
        }
    }
    Node Query(int t, int x, int y, int tgt) {
        if (f[t].l >= x && f[t].r <= y) {
            auto it = upper_bound(f[t].begin(), f[t].end(), tgt);
            if (it == f[t].begin())
                return Node();
            return *(it - 1);
        }
        if (f[t].l > y || f[t].r < x) {
            return Node();
        }
        return Query(t * 2, x, y, tgt) + Query(t * 2 + 1, x, y, tgt);
    }
} sgTree;

signed main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    cout.tie(0);
    cin >> n >> m >> k;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
    }
    for (int i = 1; i <= n; i++) {
        cin >> b[i];
    }
    sgTree.build(1, 1, n + m);
    int cnt = n;
    for (int i = 1; i <= m; i++) {
        int t;
        cin >> t;
        if (t == 1) {
            cin >> l >> r >> x;
            l ^= ans * k;
            r ^= ans * k;
            x ^= ans * k;
            int nds = sgTree.Query(1, l, r, x).cnt;
            ans = nds;
            cout << ans << endl;
        } else {
            cin >> x >> y;
            x ^= ans * k;
            y ^= ans * k;
            sgTree.Modify(1, ++cnt, x, y);
        }
    }
}
```
